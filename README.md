# 每月供应商质量退货金额统计工具

把品质部每月手工统计各供应商质量退货金额的流程（Excel 透视 + VLOOKUP，约 17 步）自动化：
网页上传 6 个导出文件 → 自动计算 → 产出与手工版式一致的结算报告 + 供应商 PDF，
部署在阿里云 ECS 上通过浏览器使用。

- **线上地址**：<http://120.25.100.51/supplier-return/>
- **代码仓库**：GitHub `sticoom/supplier-return-report`（私有）
- **服务器**：`root@120.25.100.51:/opt/supplier-return-report`（systemd 服务 `supplier-return`，nginx 80 端口子路径反代 → 127.0.0.1:8300）

## 一、计算逻辑（完整业务规则）

### 1. 输入文件（每月上传，网页 6 个独立文件位）

| # | 文件 | 来源 | 用途 |
|---|------|------|------|
| 1 | 《退货(FBA)订单导出》.xlsx | 领星 → 统计 → 退货分析 → 退货订单 | 质量退货订单明细 |
| 2 | 《退货(FBM)订单导出》.xlsx | 同上 | 同上（退货原因带 `CR-` 前缀） |
| 3 | 《DLM退货统计SKU导出》.xlsx | 图南BI → 品质 → 退货统计（选上月日期区间） | SKU 的销量 / 退货量 |
| 4 | 《采购入库单》.xlsx | 图南 → 库存中心 → 采购入库单（**日期范围 2026-01-01 至报告月末**） | 单价 + 交货分摊依据 |
| 5 | 《2026年验货数据报表》.xlsx | 飞书知识库 | 批次合格率（两种格式都支持：`26年验货原始数据` 明细页 / `供应商` 汇总页） |
| 6 | 《供应商框架合同、质量协议及廉洁协议签订记录表》.xlsx | 飞书电子表格导出 | 质量协议版本（V2/V3/V4/未签） |

参考文件（5、6）首次必传，数据更新后重传即覆盖；同批多份同类月度文件自动保留数据量大的那份。

### 2. 质量退货筛选与计数

1. FBA 筛选 `退货原因 ∈ {DEFECTIVE(存在瑕疵), MISSING_PARTS(部分零件缺失), QUALITY_UNACCEPTABLE(质量未达到期望)}`；FBM 同名原因带 `CR-` 前缀
2. **全部计入，不做买家备注剔除**（用户拍板 2026-08-19）；带备注的订单另出「买家备注复核清单」sheet 供品质部人工复核
3. 按 SKU × 三种原因 求和退货数量，SKU 的销量/退货量取自 DLM 表（按 SKU 聚合多店铺行）

### 3. 供应商归属：按交货数据分摊（用户拍板，不分一供二供）

4. 每个 SKU 的质量退货费用，按**采购入库单中各供应商对该 SKU 的交货数量占比**（入库日期 ≤ 报告月月末）分摊给所有交过货的供应商
5. **无交货记录的 SKU 整体剔除**（不计算、不出现在任何清单）——入库单从 1 月起没有它 = 早已不再交货的老品；若剔除占比 ≥30% 会在「数据校验」置顶告警（防传错/范围太窄）
6. 分摊数量出现小数时**往上取整**（用户拍板 2026-08-20，不四舍五入；多家合计可能略大于原始件数）

### 4. 单价与金额

7. 单价 = 该 SKU × 该供应商 **报告月月末之前最近一次入库的「含税单价」**（同一 SKU 多个单价取最近入库日期；实证：不含税×1.13 = 人工表单价）
8. 质量退货金额 = 分摊后数量 × 单价；应扣金额 = 该供应商全部 SKU 金额之和
9. 质量退货率 = (D+M+Q) ÷ 销量（Excel 公式）

### 5. 考核系数（乘系数前判 <200）

| 协议版本 | 100% | 95%含-100% | 90%含-95% | 80%含-90% | <80% |
|---------|------|-----------|-----------|-----------|------|
| 未签 / V2 | ×1.0（费用是多少就多少） | | | | |
| V3 | ×0 | ×0.2 | ×0.5 | ×0.8 | ×1.2 |
| V4 | ×0 | 97%含-100%:×0.2 | 95%含-97%:×0.5；90%含-95%:×0.8 | | <90%:×1.2 |

- 批次合格率 = 报告月验货记录 合格批数÷总批数（汇总页的供应商简称自动映射全名：入库供应商 > DLM > 协议表 分层唯一包含匹配）
- 本月无验货 → 系数 0，备注「本月无验货」
- 应承担金额 = round(应扣金额 × 考核系数)

### 6. 低于 200 与季度累计（月度累加）

- **按应扣金额（乘系数前）判断**：<200 进「低于200清单」，≥200 进正式月度结算
- 每月结果存 SQLite；**季度累计自动合成**：每次生成即把当月 <200 供应商的应扣/应承担累加，按季度分组（1-3月/4-6月/7-9月/10-12月），新季度重新起算

## 二、输出

### 主工作簿 `YYYY年M月供应商质量退货金额汇总表.xlsx`

| Sheet | 内容 |
|-------|------|
| 供应商费用明细 | 全部供应商汇总：应扣金额 / 批次合格率 / 协议版本 / 系数 / 应承担金额 |
| 各供应商结算清单（≥200） | 版式复刻手工「枫悦」sheet：微软雅黑、横向合并标题、两行表头、公式化退货率、统计金额/考核系数/考核金额、备注一格两行、签字栏 |
| 季度累计 | 本季度逐月明细 + 季度小计 |
| 买家备注复核清单 | 带买家备注的质量退货订单（人工复核用） |
| 供应商批次合格率 | 供应商 × 月份矩阵（总批数/不合格批数/合格率） |
| 数据校验 | DLM缺失SKU / 协议未匹配 / 剔除占比告警等 |

### 低于200工作簿 `…（低于200）.xlsx`

低于200清单（含所属季度）+ <200 供应商结算清单，与主报告分开。

### 供应商 PDF 打包 zip

- **仅 ≥200 供应商**（低于200 不生成 PDF），每家一个文件，命名 `年-月供应商全名.pdf`
- PDF 版式：横向 A4、72% 缩放整表一页宽；「按交货比例分摊」备注在 PDF 中不出现（xlsx 保留）
- 由 LibreOffice（服务器已装 libreoffice-calc + Noto CJK 字体）转换生成

### 显示格式（2026-08-20 统一）

金额两位小数；合格率一位小数（97.3%）；数量整数。

## 三、使用（网页）

1. 打开 <http://120.25.100.51/supplier-return/>（默认报告月=上个月）
2. 6 个文件位各点「选择文件」
3. 点「生成报告」——自动上传 + 计算，出现三个下载按钮（主报告 / 低于200 / PDF zip）
4. **历史报告**：按月查看，可直接重新下载该月的主报告 / 低于200 / PDF（服务器保留产物，无需重传重算）
5. **季度累计**：查看当前月所在季度的 <200 供应商逐月累计

## 四、技术

- Python 3.10+ / FastAPI + uvicorn / openpyxl + pandas / SQLite / 原生 HTML+JS 单页
- LibreOffice headless（PDF 转换）

```
engine/   loaders.py 输入解析 / rules.py 纯函数规则 / report.py 版式输出 /
          pipeline.py 编排+SQLite+PDF+CLI / models.py 契约数据类
web/      main.py FastAPI + static/index.html 单页
deploy/   service.py 部署产物（systemd unit / 探活）
tests/    59 个测试：合成 fixture 单测 + 合成数据 CLI 全量 E2E + 真实数据集成（-m integration）
data/     运行时目录（gitignore）：uploads/ reports/ pdfs/ reference/ app.db
```

```bash
pip install -r requirements-dev.txt   # 开发
python -m pytest -v                   # 单测 + 合成 E2E（默认跳过真实数据集成）
python -m pytest -m integration -v    # 真实数据集成（需本机样例文件）

# CLI 全量（含 PDF 需 --pdf 与本机 soffice）
python -m engine.pipeline --month 2026-07 --fba … --fbm … --dlm … --inbound … \
  --inspection … --agreements … --out data/reports [--pdf]

# Web 本地
python -m uvicorn web.main:app --port 8300
```

## 六、已知边界与规则演变

- **买家备注不自动剔除**（2026-08-19 拍板）：差异订单全部在复核清单里由品质部人工处理
- **单价口径曾三改**：不含税 → 首次入库含税（7月人工表实证）→ **最近入库含税**（2026-08-20 用户确认，当前生效）
- DLM 导出请在报告月初及时做，拖久了晚到订单会回填历史月份数据
- 验货「供应商」汇总页的简称靠唯一包含匹配映射，歧义简称会列在「数据校验」
- 真实数据集成测试依赖本机 `D:/Downloads` 样例文件，缺失自动 skip
